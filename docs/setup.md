# Установка и проверка отображения

## Требования

Minecraft Java 1.12.2 с Forge 14.23.5.2859 и установленным RE:volution Mod. Текущий мод v1.1.7 использует набор ресурсов v1.1.0. Версии мода на клиенте и сервере должны совпадать.

## Выбор варианта

В [релизе v1.1.0](https://github.com/Theyyk/re-volution-resource-pack/releases/tag/v1.1.0) доступны два ZIP:

- `re-volution-resource-pack-v1.1.0-64x64.zip` — меньший объём текстур;
- `re-volution-resource-pack-v1.1.0-128x128.zip` — более высокое разрешение.

Оба варианта содержат одинаковые 11 изображений и используют одинаковые пути. Они не меняют игровую логику, геометрию интерфейса или размер слотов.

## Установка

1. Скачайте один ZIP и поместите без распаковки в папку `resourcepacks` нужного профиля Minecraft.
2. Включите набор в настройках ресурсов. Одновременно выбирайте один вариант разрешения.
3. Убедитесь, что другой активный набор с более высоким приоритетом не перекрывает пространство имён `customguimod`.
4. Подключитесь к серверу с той же версией мода и откройте интерфейс клавишей `C`.
5. Проверьте отображение рун. Для повторной загрузки ресурсов используется `F3+T`.

Сам набор ресурсов не запускает сервер и не настраивает базу данных. [Установка мода, MongoDB и запуск сервера](https://github.com/Theyyk/re-volution-mod/blob/main/docs/setup.md).

## Если текстуры отсутствуют

Проверьте, что выбран правильный профиль Minecraft и набор включён. В корне ZIP должны находиться `pack.mcmeta` и `assets/`, без внешней папки репозитория. Имена и пути изображений должны совпадать с каталогом мода: `customguimod:textures/gui/runes/<name>.png`.

После замены набора перезагрузите ресурсы или полностью перезапустите клиент. При проверке новых текстур проверьте первый запуск интерфейса и несколько размеров окна; успешная проверка PNG и ZIP сама по себе не подтверждает правильное отображение в игре.
