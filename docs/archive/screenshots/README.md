# Архив GUI-скриншотов

Эта папка хранит исторические runtime-скриншоты RE:volution, которые раньше использовались для демонстрации Resource Pack.

Они сохранены только как архив и могут показывать устаревшее состояние интерфейса основного мода. Текущий README больше не использует GUI-скриншоты как актуальный preview: вместо них он показывает постоянный showcase фактических rune assets в вариантах 64×64 и 128×128.
