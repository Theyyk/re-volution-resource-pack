# Набор ресурсов — визуальные заметки

Набор ресурсов RE:volution хранит только визуальные ресурсы, которые могут быть заменены без изменения игровой логики основного Forge-мода.

## Правила визуального набора

- основной объект должен хорошо читаться в небольшом слоте интерфейса;
- изображение не содержит текста, ранга или значка типа;
- фон прозрачный;
- основной вариант текстур рун — `128x128`, дополнительный — `64x64`;
- основной стиль — тёмное фэнтези в стилистике Minecraft;
- базовая палитра — чёрный, тёмно-серый, приглушённый зелёный, серебро;
- золото используется как редкий акцент;
- эффект и назначение предмета важнее буквального соответствия статусу Яд.

Ранг, тип, состояние получения, наведение курсора и остальные элементы интерфейса формируются отдельно от предметной иконки.

## Структура ресурсов

Текущая структура:

```text
assets/customguimod/textures/gui/runes/                 # 128×128
variants/64x64/assets/customguimod/textures/gui/runes/  # 64×64
```

Планируемая структура:

```text
assets/customguimod/textures/gui/
├─ runes/
├─ ranks/
├─ status/
├─ types/
├─ buttons/
└─ backgrounds/
```

## Граница ответственности

Набор ресурсов:

- PNG-текстуры;
- визуальное оформление интерфейса;
- будущие атласы интерфейса и декоративные элементы.

Основной мод:

- каталог и порядок рун;
- состояние получения и ранга;
- игровая логика;
- сетевой код;
- MongoDB;
- пути `ResourceLocation`;
- выбор и рендер нужного визуального ресурса.

[Репозиторий основного мода](https://github.com/Theyyk/re-volution-mod).

## Проверка перед релизом

После изменения изображений необходимо:

1. проверить отображение в Minecraft с подключённым набором ресурсов;
2. проверить первый запуск интерфейса после полного перезапуска клиента;
3. проверить несколько размеров интерфейса;
4. убедиться, что отсутствующие или переименованные пути не приводят к отсутствующим текстурам;
5. только после визуальной проверки включать изменения в релизную ветку.
