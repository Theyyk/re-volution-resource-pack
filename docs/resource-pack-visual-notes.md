# Resource Pack — визуальные заметки

RE:volution Resource Pack хранит только визуальные ресурсы, которые могут быть заменены без изменения игровой логики основного Forge-мода.

## Правила визуального набора

- основной объект должен хорошо читаться в небольшом GUI-слоте;
- изображение не содержит текста, ранга или бейджа типа;
- фон прозрачный;
- целевой размер rune-текстур — `128x128`;
- основной стиль — тёмный fantasy / Minecraft-inspired;
- базовая палитра — чёрный, тёмно-серый, приглушённый зелёный, серебро;
- золото используется как редкий акцент;
- эффект и назначение предмета важнее буквального соответствия статусу Яд.

Ранг, тип, состояние получения, hover и остальные элементы интерфейса формируются отдельно от предметной иконки.

## Граница ответственности

Resource pack:

- PNG-текстуры;
- визуальное оформление GUI;
- будущие UI-атласы и декоративные элементы.

Основной мод:

- каталог и порядок рун;
- состояние получения и ранга;
- игровая логика;
- сетевой код;
- MongoDB;
- пути `ResourceLocation`;
- выбор и рендер нужного визуального ресурса.

Основной репозиторий: https://github.com/Theyyk/re-volution-mod

## Проверка перед релизом

После изменения изображений необходимо:

1. проверить отображение в Minecraft с подключённым resource pack;
2. проверить первый запуск GUI после полного перезапуска клиента;
3. проверить несколько размеров GUI;
4. убедиться, что отсутствующие или переименованные пути не дают missing texture;
5. только после визуальной проверки включать изменения в релизную ветку.
