# RE:volution Resource Pack v1.0.0

Первый публичный выпуск набора ресурсов для Minecraft 1.12.2.

## Добавлено

- 11 уникальных изображений рун первого статуса Яд.
- Текстуры PNG 128×128 в пространстве имён `customguimod`.
- Формат набора ресурсов 3 и автоматическая сборка ZIP через GitHub Actions.

## Исправления

Отдельные исправления ошибок для этого выпуска не указаны.

## Прочее

Размер текстур оптимизирован до 128×128. Игровая логика и состояние рун остаются в основном моде.
