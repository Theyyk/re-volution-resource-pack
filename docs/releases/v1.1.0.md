# RE:volution Resource Pack v1.1.0

Обновлён визуальный набор рун Яда и введена поставка в двух разрешениях.

## Добавлено

- Перерисованы все 11 уникальных текстур в едином детальном пиксельном стиле.
- Добавлены два варианта: 64×64 и 128×128.
- Оба варианта используют версию v1.1.0 и одинаковые имена и пути ресурсов.
- Автоматизация проверяет оба разрешения и собирает два отдельных ZIP.

## Исправления

Отдельные исправления ошибок для этого выпуска не указаны.

## Прочее

Сохранены пространство имён `customguimod` и совместимость с 26 фиксированными позициями рун. Проверены прозрачные PNG RGBA; оба варианта проверены в Minecraft 1.12.2 согласно исходному описанию релиза.

Набор содержит только изображения рун Яда. Отдельные категории изображений рангов, статусов, типов, кнопок и других элементов интерфейса запланированы на будущие версии. Это описание не означает повторную проверку в игре при изменении документации.

## Загрузка

[Релиз v1.1.0](https://github.com/Theyyk/re-volution-resource-pack/releases/tag/v1.1.0):

- `re-volution-resource-pack-v1.1.0-64x64.zip`;
- `re-volution-resource-pack-v1.1.0-128x128.zip`.

Выберите один вариант. Геометрию и поведение интерфейса задаёт мод.
